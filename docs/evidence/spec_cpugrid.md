## 4. 曲线

### 4.1 ⚠️ 关于填充（重点）

**结论：有填充，但极淡。**

判定方法（排除网格线与抗锯齿干扰）：以每一列「该列第一个强蓝像素」为曲线的 y，
分别统计曲线上方 6~12px 与下方 6~12px 的 `B−R` 中位数（跳过网格线行）：

| 格子 | 曲线上方（中位数） | 曲线下方（中位数） | 结论 |
|---|---|---|---|
| r1c1 | **1** | **11** | 有填充 |
| r1c2 | **4** | **85** | 有填充 |
| r2c1 | **3** | **71** | 有填充 |
| r2c2 | **2** | **42** | 有填充 |

干净取样（r3c3 高台内部，x=602~612，曲线在 y≈294，取 y=296~355 全深度平均）：

```
填充区 RGB(241,246,250)   B−R = 9~13
空白区 RGB(253,253,254)   B−R = 1~2
```

**填充色 `RGB(241,246,250)` ≈ `#F1F6FA`，纯色平涂，无渐变。**
（沿深度 0~60px 采样，B−R 稳定在 9~13，无单调趋势 → 不是渐变）

等效写法：曲线色 `#1B82C2` 以 **6.5% alpha** 叠在白色上：
`255−0.065×225 = 240.4`、`255−0.065×125 = 246.9`、`255−0.065×61 = 251.0` → `RGB(240,247,251)` ✔

> 为什么肉眼看着像「不填充」：`#F1F6FA` 与白色只差 14 个灰阶，
> 在 1× 缩放下几乎不可见。但只要放大 6× 或用对比度拉伸，填充边界完全跟随曲线。

### 4.2 Y 轴范围【截图实测】

- **0% → 格子下边框内侧**；**100% → 格子上边框内侧**。**全程映射，无上下留白。**
- 证据：横向网格线恰在 10%~90% 等分；row2/row3 的尖峰触到 `rel=0`（即 100%）；
  静默格基线触到 `rel=65`（即 0%，与下边框重合）。
- 绘图区高度 = 65 − 2（边框）= **63px**，故 **1% ≈ 0.63px**

### 4.3 X 轴 / 时间窗【截图实测 + 资源佐证】

- 左上角标注 `60 秒内的利用率 %` → **60 个采样点**
- 曲线**从格子左边缘（内侧第 1 个像素）画到右边缘**，横跨全部 143px 内宽
  （x=245 与 x=386 都能检出曲线像素）
- 点距 = 143 / 60 ≈ **2.38px**；实测折线顶点密度与此吻合
- 采样方向：**左 = 最旧，右 = 最新**（【资源佐证】任务管理器惯例）

### 4.4 基线【截图实测】

- **没有单独画基线**。0% 的曲线直接落在格子下边框上，两者颜色叠加变深
  （下边框 `RGB(115,176,218)` → 有曲线处 `RGB(20,119,182)`）。
- 实现时：`y(0%) = plotBottom`，即与边框重合即可，**不要额外画一条线**。

### 4.5 绘制顺序

1. 白底
2. 淡蓝填充 `#F1F6FA`（曲线到 0% 之间的多边形）
3. 横向 9 条 + 竖向 3 条网格线（`#E8F0F9` / `#DEECF5`）
4. 1px 蓝色折线 `#1B82C2`
5. （边框最后画，或作为格子轮廓）

> 顺序依据：【截图实测】填充区内网格线可见（B−R 由 10 跳到 21），
> 说明网格线画在填充之上；曲线像素最饱和且连续，说明曲线在最上。

## 附：复现用扫描方法（如需复核）

所有数字均可用下列方式在 `3.png` 上复现：

```powershell
Add-Type -AssemblyName System.Drawing
$img = [System.Drawing.Bitmap]::FromFile('<3.png 路径>')
# 边框线：找某列上连续为「蓝」(B-R>25 且 B>140) 像素数 > 阈值的 x / y
# 网格线：在格内取 100px 宽条带，逐行统计 avg < 250 的像素数
# 曲线：某列从上往下第一个 B-R >= 45~55 的 y
# 填充：曲线上方 6~12px 与下方 6~12px 的 B-R 中位数比较（跳过网格线行）
# 文字：阈值 200/150 求 bbox（注意避开 x>=858 的窗口边框）
```

**坑位提醒**
1. `x >= 858` 是窗口蓝色边框，任何右边缘取样都要避开，否则会误判颜色（这正是 `100%` 被误读成蓝色的原因）。
2. 曲线与 0% 基线/下边框重合，该处像素不代表边框色。
3. 曲线陡峭段的抗锯齿会让「曲线颜色」看起来偏浅，取最暗值才是描边色。
4. 填充只有 14 个灰阶差，看 1× 截图会误以为没有填充。
